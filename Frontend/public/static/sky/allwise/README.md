# AllWISE sky overview

The original HiPS order-3 Allsky atlas is preserved unchanged from:
https://irsa.ipac.caltech.edu/data/hips/CDS/AllWISE/RGB-W4-W2-W1/Norder3/Allsky.jpg

The original properties file accompanies it. Attribution: IPAC/NASA, WISE/NEOWISE, CDS HiPS distribution. The local atlas supplies a low-resolution sky overview when live survey services are unavailable. Higher-resolution tiles are requested from the IRSA mirror. This is contextual AllWISE sky imagery, not one of the 94 SPHEREx coadds and not an individual source photograph.
