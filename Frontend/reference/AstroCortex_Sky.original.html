Field data

The sky background is an archival AllWISE image. The 48 field frames, timestamps, source positions and class labels are generated locally for this interactive scene. They are not SPHEREx observations or results from a trained classifier.

Point-spread profiles, subpixel motion, noise, variable flux and flagged pixels are generated consistently across all six detectors. Flux is relative. Class portraits are symbols, not resolved photographs.

Connect the team API in Settings or import a field package to replace this scene with observations and classifier output.
